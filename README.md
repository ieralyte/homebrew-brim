# homebrew-brim

Homebrew tap for [Brim](https://github.com/ieralyte/brim), an open-source Dynamic Island for the MacBook notch and lock screen.

```sh
brew install --cask ieralyte/brim/brim
```

Brim needs macOS 26 Tahoe or later on Apple silicon. It isn't notarized, so the first launch is blocked once: open **System Settings → Privacy & Security** and click **Open Anyway**.

The cask is updated automatically whenever a new Brim version is released.
